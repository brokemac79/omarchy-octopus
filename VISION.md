# Vision

Make household electricity understandable at a glance in Omarchy: current Agile prices, live power when a Home Mini is available, recent usage and useful upcoming cheap windows.

The plugin should be small, local-first and honest about its data. It reads from Octopus Energy; it does not control devices, export customer data, require OpenClaw, or pretend that an estimate is a bill. Prices and costs can be negative. Incomplete or stale readings must be visible as such, never silently filled with zero.

Prioritise dependable information, privacy and native Omarchy behaviour over adding more charts or integrations. Keep price-only use possible without an API key. Broader account/tariff compatibility needs real-world verification before it is claimed.

This is an independent community project, not an official Octopus Energy or Omarchy product.
